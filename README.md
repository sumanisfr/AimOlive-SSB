## 🎯 Project Overview

**AimOlive** is a free, open platform to help SSB aspirants practice PPDT (Picture Perception & Discussion Test) and TAT (Thematic Apperception Test) in a structured, realistic, and time-bound environment.

Includes:

- Practice arena for PPDT & TAT  
- Centralized digital library of SSB preparation PDFs (OIR, GTO, SRT, WAT, etc.)  
- Responsive, modern UI optimized for mobile and desktop  
- Built for the defense aspirant community
